    How to read the chart

    The chart shows the ten newest imported threads with measured time on a shared UTC clock. Provider runs can include idle time, tool calls, or workflows. Admission lasts from run request to provider start. Unobserved gaps have no confirmed activity. Scroll vertically to see more threads. Drag the minimap to select a range, use its arrow keys to pan, or drag the UTC axis. At six hours or less, select a thread to inspect events timed from its start.
